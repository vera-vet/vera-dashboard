# Vera Dashboard

Panel de gestión para clínicas veterinarias — Fase 1 (frontend).

## Stack
Next.js 15 (App Router) · Tailwind CSS v4 · shadcn/ui · next-themes · Recharts.

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Pruebas

```bash
npm test
```
